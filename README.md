# Papertray

一个计划中的轻量 macOS 纸张便笺工具：全局快捷键唤出右上角工具盘，拖出横线纸或待办纸创建便笺，粘贴图片，并把文字与稳定图片路径复制给本机 Pi Agent。

**当前状态：只有产品与技术交接文档，尚未开发应用。**

下一位开发者请从 [HANDOFF.md](HANDOFF.md) 开始，里面包括：

- 已确认需求与建议默认交互；
- 原生 AppKit / TextKit 2 技术选型；
- 多屏拖出纸张、无限延展待办、笔色与窗口生命周期；
- 图片持久化和面向 Pi 的复制合同；
- 后续纸面/打字特效的独立渲染设计；
- 实施顺序、验收清单、风险与一手资料。

项目名为暂定名。当前没有构建命令或可运行二进制，也没有远程仓库配置。
